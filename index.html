The DevOps Journey

I — Foundation
Learn & Master

Start with the core building blocks: Linux administration, Git version control, basic networking, and shell scripting. Understand how software moves from code to execution.

II — Automation
Build & Containerize

Package applications with Docker, design automated CI/CD pipelines with Jenkins and GitHub Actions, and manage infrastructure dynamically using Terraform and Ansible.

III — Orchestration
Deploy & Scale

Orchestrate complex cloud infrastructure using Kubernetes, implement GitOps workflows with ArgoCD, and monitor application health with Prometheus and Grafana.

Frequently Asked Questions

Are the workshops and events free to attend?
Yes, all our workshops, bootcamps, and club events are completely free for university students. Everyone is welcome to attend and learn without any entry fee.
Do I need prior knowledge, or do you teach from basics?
No prior knowledge is required! We teach everything from absolute scratch—covering basic Linux commands, Git, Docker, and core DevOps fundamentals before moving to advanced topics.
Can I join as a Core Team member right now?
The Core and Junior Core positions are currently filled for this tenure. However, you can actively work with us on projects and events as a contributor to prepare for the next tenure recruitment!
How can I work with Tech, Design, Management, or PR?
If you have technical project ideas, design assets, or want to help manage events, directly contact the respective Domain Head or Co-Head to start working together on active tasks.
When will recruitments open for the next Core Team?
Recruitments for the next tenure will open toward the end of the current term. Students who actively collaborate with our domain heads throughout the year will be given strong preference.
